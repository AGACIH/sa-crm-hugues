# Sa CRM — Hugues

CRM de démonstration construit pendant l'atelier **Sa CRM**, sans écrire une
ligne de code : Next.js + TypeScript, données d'exemple dans le projet,
aucune base de données.

- Charte visuelle : https://github.com/AGACIH/crm-workshop-formation (dossier `assets/`)
- Règles du projet : voir `CLAUDE.md`

## Commandes

```
npm install
npm run verifier   # cohérence des données d'exemple
npm run build      # vérification technique
npm start          # démarre l'application
```
